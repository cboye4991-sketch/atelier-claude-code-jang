Le CLAUDE.md du projet fil rouge : l'app web Jàng

  • Plan d'abord (aucun fichier touché), puis écriture : 96 lignes, 9 sections. Stack : Vite, React, TypeScript strict, Firebase Hosting et Functions, avec la clé Dify en secret côté serveur.
  • /context : la case « Memory files » pèse 2,3k tokens (CLAUDE.md et ta mémoire utilisateur). Commit c42f2fa CLAUDE.md sur phase-1.
## Never
- Never commit `.env*` or `functions/.secret.local`.
- Never call Dify from the client. Never expose `DIFY_API_KEY` in the bundle, logs or responses.
- Never invent exercises, reference answers, users or figures. Use real data or a clearly
  marked placeholder.
- Never change an exercise ID without updating the knowledge base in the same change.
- Never touch Firebase rules (Firestore, Storage, Hosting headers for access) without asking.
  Never leave test-mode rules.

Récupérer le travail sur Windows

Décompresse claude-lab-jang.zip dans ton dossier personnel, puis, dans PowerShell :

New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Copy-Item "$HOME\claude-lab\04-memoire-utilisateur\CLAUDE.md" "$HOME\.claude\CLAUDE.md"
Copy-Item -Recurse "$HOME\claude-lab\05-brand\_a-copier-dans-.claude\skills\jang-brand" "$HOME\.claude\skills\"
cd "$HOME\claude-lab\00-installation"; .\verif-windows.ps1

Si tu as déjà un $HOME\.claude\CLAUDE.md, ne l'écrase pas : colle le contenu à la fin. Le README.md de l'archive détaille tout. Les prompts exacts sont dans _prompts/, et la transcription de chaque session dans _journal/.
